# Claude Desk

Desktop UI for Claude Code built on the Claude Agent SDK. It runs the regular
Claude Code that is installed and signed in on this machine, so it uses your
own Claude subscription. For personal use only.

## Run

```
npm install
npm run build
npm start
```

Development with hot reload: `npm run dev`.

Windows installer (`release\Claude Desk Setup <version>.exe`):

```
npm run dist
```

Or a Desktop / Start menu shortcut to this folder (no console window):

```
npm run shortcut
```

## Features

- Codex-style layout: projects and chats from Claude Code, plan limits, account.
- Model and effort picker (slider), permission modes, all switchable mid-session.
- Streaming steps (commands, edits with diffs, reads, searches, subagents, plan),
  "worked for …" summary, approvals with diffs, questions and plan review.
- Changes panel with every file edited in the chat; "Open in" VS Code / JetBrains / Terminal.
- Short chat titles generated by Haiku after the first reply (setting `autoTitles`).
- Image attachments, slash commands, queued follow-ups, notifications, light/dark theme.
- Background tasks bar, Agents panel (live subagent transcripts), Git tab with commit/push/branches.
- Context usage ring with compact, file rewind to any message, chat forks.
- Worktree mode: a chat runs in its own git worktree/branch; apply changes back with one click.
- Settings window (Ctrl+,).

## Layout

- `electron/claude.mjs` — bridge to the Agent SDK: one long-lived streaming query per chat,
  live model / effort / permission-mode switching, tool approvals, interrupts, session history.
- `electron/main.mjs` — window, IPC, settings (`%APPDATA%\Claude Desk\settings.json`).
- `renderer/src` — React UI (Zustand store, Motion animations).

## Shortcuts

- `Enter` send, `Shift+Enter` new line, `Esc` stop the current turn
- `Ctrl+N` new chat, `Ctrl+B` toggle sidebar, `Ctrl+Shift+I` DevTools
- `/` in an empty composer lists slash commands and skills
